## สรุป 5 สิ่งทำทันที

1. **เปลี่ยน Hook** — ใช้ Hook จาก `hook-formulas.md` แทนการเริ่มด้วย "สวัสดีครับ"
2. **ออกแบบ Thumbnail ใหม่** — ใส่หน้าตัวเอง + ตัวเลขใหญ่ ดู `thumbnail-guide.md`
3. **ใช้ Script Template** — ดู `script-templates.md` เลือก template ที่เหมาะกับคลิป
4. **โพสต์ตามเวลาที่กำหนด** — 07:00 / 12:00 / 20:00 (จ-ศ), ดู `content-calendar-template.md`
5. **เน้น "มุมมองเภสัชกร"** — นี่คือ unique angle ที่ไม่มีใครทำในตลาด
